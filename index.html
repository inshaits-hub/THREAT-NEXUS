Detection Engine Scope

  • SSH Brute-Force: Triggers when failed SSH login attempts exceed threshold (>5 in 60s) from single IP.
  • Web Vulnerability Scans: Flags SQL Injection (`UNION SELECT`), XSS (`<script>`), and directory traversal (`../`).
  • Anomaly Detection: Unusually high volume requests per minute and off-hour admin login activity.
  • IP Reputation Score: Dynamic scoring based on past flag counts within dataset.

Academic Compliance

  • Modular Architecture: 5 distinct Python source files separated cleanly from web frameworks.
  • Standalone CLI Option: Capable of executing pure CLI analysis via `python main.py --log filepath`.
  • Testing Coverage: Pytest unit tests for log regex parsers and threat detection heuristics.
  • Zero External Hardware: Runs seamlessly on any standard laptop without complex dependencies.

Flask REST API Endpoint Specifications

Inter-module communication interface connecting `app.py` backend with the Web Dashboard.

Interactive API Documentation Base URL: http://localhost:5000
GET /api/v1/summary
Dashboard Metrics

Returns aggregate counts for total events, threat alerts, critical items, and unique malicious IPs.

{ "total_events": 18420, "total_threats": 47, "critical_threats": 6, "unique_ips": 23 }
POST /api/v1/upload
Log File Ingestion

Accepts log file upload via standard `multipart/form-data`, triggers parser engine and stores results in SQLite.

{ "status": "success", "filename": "auth.log", "parsed_events": 1420, "threats_detected": 12 }
GET /api/v1/threats
Threat Alerts List

Returns list of flagged security incidents filtered optionally by IP or severity level query string parameters.

[ { "id": 1, "type": "Brute-force SSH", "ip": "192.168.1.50", "severity": "CRITICAL", "attempts": 37 } ]
GET /api/v1/export/report
Executive Report Download

Invokes `report_generator.py` to compile current analysis into a downloadable HTML or JSON report file.
